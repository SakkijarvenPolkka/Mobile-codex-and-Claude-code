# 파일 탐색기 (Files) — Windows 11 탐색기 스타일 파일 관리자

휴대폰의 내부 저장소·SD 카드·USB 드라이브를 Windows 11 파일 탐색기처럼 찾아보고, 복사·이동·삭제·이름 바꾸기·압축을
하고, 이미지·텍스트·오디오·동영상·PDF를 앱 안에서 보는 Android 파일 관리자입니다. Kotlin과 Jetpack Compose
Foundation 위에 Fluent 스타일 컴포넌트를 직접 만들어 얹었습니다(Material 3를 쓰지 않습니다).

> **비공식 앱입니다.** Windows 탐색기의 모습과 동작을 참고했을 뿐, Microsoft와 관련이 없고 그들의 승인을 받지
> 않았습니다. Windows는 Microsoft의 상표입니다. Microsoft의 이름·로고·아이콘 파일은 쓰지 않았고, 아이콘은
> 모두 벡터로 직접 그렸습니다. 앱 이름은 한국어 "파일 탐색기", 영어 "Files"입니다.

English summary: a standalone Android file manager that looks and behaves like the Windows 11 File Explorer
(Fluent design, command bar, tabs, home, light/dark). Unofficial look-alike, not affiliated with Microsoft.
It needs the "All files access" permission, runs on Android 11+, and has no third-party libraries. MIT license.
See [Install](#설치) and [Build](#빌드).

이 앱은 같은 저장소의 Audacity 포팅(`:app`, `:engine`, `:editor`, `native/`)과 코드·빌드 의존이 없는 별개의
앱입니다.

## 기능

### 탐색

- **보기 4가지**: 자세히(이름·수정한 날짜·유형·크기 열), 목록, 타일, 큰 아이콘(썸네일 격자). 폴더마다 기억합니다.
- **정렬**: 이름·수정한 날짜·유형·크기, 오름/내림차순, 폴더 먼저. 열 머리글을 탭해도 정렬됩니다. 이름은 한글 NFC
  정규화, 대소문자 무시, 숫자 부분은 수치로 비교합니다(`2.txt` < `10.txt`).
- **주소 표시줄**: 경로 조각(브레드크럼)을 탭하면 그 폴더로, 조각 옆 ▾는 하위 폴더 목록, 빈 곳을 탭하면 실제 경로를
  직접 입력. 뒤로/앞으로/위로 버튼.
- **탭**: 가로 스크롤 탭 줄, 새 탭, 닫기, 다른 탭 닫기, 복제. 탭과 위치는 앱을 다시 열어도 복원됩니다.
- **홈**: 빠른 액세스(즐겨찾기와 다운로드·DCIM·사진·문서·음악·동영상), 드라이브별 사용량 막대, 최근 항목 20개,
  휴지통 크기.
- **즐겨찾기**: 폴더 고정/해제와 순서 바꾸기.
- **탐색 창**: 홈, 즐겨찾기, 내 PC(볼륨 목록), 휴지통. 휴대폰은 서랍, 너비 840dp 이상에서는 왼쪽에 고정되고 오른쪽에
  미리보기 창이 붙습니다.
- **그 밖에**: 숨김 항목·파일 확장자 표시 설정, 속성 대화상자(폴더는 하위 항목을 세며 갱신), 밝게/어둡게/시스템 테마와
  시스템 강조색, 하드웨어 키보드 단축키(Ctrl+C/X/V/A, Delete, Shift+Delete, F2, F5, Ctrl+L, Ctrl+T/W,
  Ctrl+Tab, Alt+←/→/↑, Enter, Alt+P).

### 파일 작업

- 새로 만들기(폴더, 텍스트 문서), 복사·잘라내기·붙여넣기, 이름 바꾸기(확장자를 바꾸면 확인, 대소문자만 바꾸는 이름
  변경 지원), 삭제, 공유, 다른 앱으로 열기, APK 설치.
- **충돌 처리**: 대상 덮어쓰기 / 건너뛰기 / 둘 다 유지, "이후 충돌에도 모두 적용". 같은 이름의 폴더는 병합합니다
  (대상에만 있는 파일은 그대로 남습니다). 같은 폴더에 붙여넣으면 `- 복사본`으로 복사합니다.
- **휴지통**: 볼륨마다 `.Recycle.Bin`. 복원, 영구 삭제, 비우기. 휴지통으로 옮길 수 없으면 조용히 지우지 않고 영구 삭제 여부를 묻습니다.
- **백그라운드 진행**: 진행률 대화상자, 상태 표시줄의 진행률 칩, 데이터 동기화 포그라운드 서비스와 알림(취소 가능).
  화면을 꺼도 계속되고, 충돌이 있으면 알림이 "확인이 필요합니다"로 바뀝니다.
- **중단에 안전한 쓰기**: 임시 파일(`.xpart`)에 쓴 뒤 이름을 바꿔 확정합니다. 취소, 공간 부족, SD 카드 제거,
  강제 종료에도 원본은 지워지지 않고 잘린 파일이 완전한 파일처럼 남지 않습니다. 작업 저널이 앱을 다시 열 때
  남은 임시 파일을 정리하고 "작업이 중단되었습니다: X/Y 완료 — 다시 시도"를 보여 줍니다.
- 복사한 파일은 미디어 스캔을 해서 갤러리에 나타납니다.

### 미리보기

- **이미지**: JPG·PNG·WebP·GIF·HEIC·BMP·AVIF. 핀치/두 번 탭 확대(확대하면 더 높은 해상도로 다시 디코딩),
  좌우로 넘겨 같은 폴더의 이전/다음 이미지, 애니메이션 GIF/WebP.
- **텍스트**: UTF-8, UTF-16(BOM), 한국어 CP949를 자동 감지하고 ⋯에서 직접 고를 수도 있습니다. 줄 번호, 고정폭 글꼴,
  최대 1 MiB. 바이너리 파일은 다른 앱으로 넘깁니다.
- **오디오·동영상**: Fluent 재생 컨트롤, 오디오 포커스 처리, 이어폰이 빠지면 일시정지, 앱이 가려지면 일시정지하고
  돌아오면 그 위치에서 다시 준비.
- **PDF**: 세로 스크롤, 핀치 확대, 암호 PDF·손상된 파일 안내.
- **썸네일**: 큰 아이콘·타일 보기와 미리보기 창에서 이미지·동영상·오디오 썸네일(캐시, 스크롤하면 취소).
- 미리보기를 지원하지 않는 형식이나 실패한 경우에는 "다른 앱으로 열기"를 제안합니다.

### 검색

- 현재 폴더(하위 폴더 포함)에서 파일 이름 검색. 부분 문자열과 `*`/`?` 패턴, 한글 NFC·대소문자 무시.
- 찾는 대로 결과가 채워지고, 현재 순회 중인 폴더와 건너뛴 폴더 수를 보여 줍니다. 최대 10,000개.
- 결과에서 열기·복사·잘라내기·삭제·이름 바꾸기·압축이 되고, 뒤로 가면 원래 폴더로 돌아갑니다.

### ZIP

- 선택한 항목을 ZIP(UTF-8 이름)으로 압축, "모두 압축 풀기".
- **한국어 ZIP**: Windows(한국어)에서 만든 CP949 이름을 자동 감지해 풀고, 대화상자에서 자동 / UTF-8 / 한국어 CP949를
  고를 수 있습니다. macOS의 NFD 한글 이름도 NFC로 바로잡습니다.
- **안전한 풀기**: `..` 조각·절대 경로·드라이브 접두어(`C:`)·제어 문자가 든 이름이 하나라도 있으면 아무것도 풀지 않고
  거부합니다(역슬래시는 `/`로 바꿉니다. Android 14+의 `ZipPathValidator`가 거부해도 같은 메시지). 선언 크기를 넘거나
  CRC가 다른 항목은 중단하고, 임시 폴더에 푼 뒤 통째로 이름을 바꿔 확정합니다.
- 암호 ZIP은 지원하지 않습니다(암호로 보호된 ZIP이라는 안내만 합니다).

### 언어와 라이선스

- 한국어/영어 UI(시스템 언어를 따름). 새 서드파티 라이브러리 없음(androidx와 kotlinx만).
- 라이선스: MIT ([`LICENSE`](LICENSE)). 저장소 루트의 Audacity 포팅(GPL)과는 별개입니다.

### 하지 않는 것 (v1)

클라우드·네트워크 드라이브(SMB/FTP), 루트 권한, 파일 내용 검색, 7z/RAR, 암호 ZIP·암호 PDF 열기, ZIP 안을 폴더처럼
탐색하기, 백그라운드 음악 재생, 텍스트 편집, 실행 취소(Ctrl+Z), 드래그 앤 드롭, 여러 창, 위젯.

## 설치

Android 11(API 30) 이상이 필요합니다.

1. 릴리스 빌드로 만든 `explorer-release.apk`(빌드 참고)를 기기로 옮깁니다. 기기에서 "출처를 알 수 없는 앱 설치"를
   허용한 뒤 APK를 엽니다(sideload).
2. 처음 실행하면 **모든 파일 관리** 권한 화면이 나옵니다. 버튼을 눌러 설정에서 이 앱의 "모든 파일에 대한 액세스"를
   켜고 돌아오면 됩니다. 권한이 없으면 앱은 다른 화면을 보여 주지 않습니다.
3. Android 13 이상에서는 파일 작업의 진행 알림을 위해 알림 권한을 한 번 묻습니다(거부해도 작업은 동작합니다).

APK는 디버그 키로 서명되어 있어 바로 설치할 수 있습니다. 배포용으로는 별도 키로 다시 서명하세요.

## 빌드

필요한 것: JDK 17 이상, Android SDK(platform 36, build-tools 36.0.0). 저장소 루트의 `local.properties`에 SDK 위치를
적습니다(커밋하지 않는 파일).

```properties
sdk.dir=/opt/android-sdk
```

이 앱은 Audacity 네이티브 엔진을 쓰지 않으므로 **모든 Gradle 명령에 `-Paudacity.buildNative=false`를 붙입니다**
(안 붙이면 NDK 빌드가 시작됩니다).

```sh
# 디버그 APK → explorer/build/outputs/apk/debug/explorer-debug.apk
./gradlew -Paudacity.buildNative=false :explorer:assembleDebug
# 릴리스 APK(R8 축소, 디버그 키 서명) → explorer/build/outputs/apk/release/explorer-release.apk
./gradlew -Paudacity.buildNative=false :explorer:assembleRelease
```

Maven Central이 HTTP 429를 돌려주면 잠시 뒤 같은 명령을 다시 실행하세요(Google 미러가 대체 저장소로 설정되어 있습니다).

### 테스트

```sh
# 단위·Robolectric Compose 테스트 전체 + 디버그 빌드 (각 변경의 통과 기준)
./gradlew -Paudacity.buildNative=false :explorer:testDebugUnitTest :explorer:assembleDebug
# 일부만
./gradlew -Paudacity.buildNative=false :explorer:testDebugUnitTest --tests '*ZipTest'
```

테스트 결과는 `explorer/build/test-results/testDebugUnitTest/`와 `explorer/build/reports/tests/`에 있습니다.
Gradle을 두 개 동시에 실행하지 마세요.

## 구조

소스는 `explorer/src/main/java/io/github/sakkijarvenpolkka/explorer/`에 있습니다. 위 층이 아래 층만 사용합니다
(`LayeringTest`가 확인합니다).

- `ui/`, `ui/fluent/` — 화면(셸, 홈, 대화상자, 단축키)과 직접 만든 Fluent 컴포넌트·아이콘
- `preview/` — 이미지·텍스트·오디오/동영상·PDF 뷰어와 미리보기 창
- `state/` — ViewModel, 탭·위치·선택·명령 활성화 같은 UI 상태
- `ops/` — 작업 실행기, 포그라운드 서비스, 작업 저널, 알림
- `data/` — 설정과 세션 저장
- `platform/` — 볼륨 레지스트리, 다른 앱으로 열기, 썸네일, 미디어 스캔, 권한
- `fs/` — 파일 시스템 계층(Android API 없음): 쓰기 규칙, 파일 작업, 휴지통, 순회기, 검색, ZIP, 이름 검사·정렬, 텍스트 감지
- `util/` — 표시 이름, 크기·날짜 형식, `UiText`

설계 문서: [`docs/superpowers/specs/2026-10-23-explorer-design.md`](../docs/superpowers/specs/2026-10-23-explorer-design.md)

## 실기기 확인 목록

이 앱은 에뮬레이터가 없는 환경에서 만들었습니다. 단위·Robolectric 테스트(686개)는 통과하지만, 아래는 실제
기기에서 직접 확인해야 합니다. 확인한 항목에 체크하세요. 문제가 있으면 기기, Android 버전, 저장소 종류(내부/SD/USB)와
함께 알려 주세요.

### 저장소와 권한

- [ ] SD 카드에서 새로 만들기·복사·이동·이름 바꾸기·삭제(휴지통 포함)가 된다
- [ ] USB OTG 드라이브: 권한을 받기 전에 연결했을 때 "앱을 다시 시작하면 이 드라이브를 열 수 있습니다"와 다시 시작
      동작, 권한을 받은 뒤에는 바로 열린다
- [ ] `Android/data`·`Android/obb` 폴더에서 "Android에서 제한한 폴더" 배너가 보이고 새로 만들기·붙여넣기·이름
      바꾸기가 막힌다
- [ ] SD에 있는 파일을 다른 앱으로 열 수 있다(FileProvider, `/storage/XXXX-XXXX/...`)
- [ ] APK를 탭하면 "출처를 알 수 없는 앱" 안내를 거쳐 설치 화면이 열린다

### 파일 작업

- [ ] 화면을 끈 채 10분 이상 걸리는 큰 복사가 끝까지 진행된다(포그라운드 서비스, 알림, WAKE_LOCK)
- [ ] 복사 중 SD 카드를 뽑으면 작업이 "N/M 완료"로 멈추고, 임시 파일이 남지 않으며, 앱이 종료되지 않는다
- [ ] 백그라운드에서 SD 카드를 꺼내면(`ACTION_MEDIA_EJECT`, 앱이 캐시된 상태) vold가 앱을 종료하기 전에 그 볼륨의
      열린 파일(미리보기·썸네일·PDF·미디어)이 닫힌다
- [ ] 복사 중 설정에서 전체 파일 접근 권한을 회수하면 앱이 종료되고, 다시 열었을 때 저널이 남은 임시 파일을 정리한다
- [ ] 이름 바꾸기 대화상자 위로 키보드가 올라와도 입력란과 버튼이 가려지지 않는다
- [ ] 내부 저장소와 SD 카드에서 대소문자만 바꾸는 이름 변경(`a.txt` → `A.txt`)이 된다
- [ ] 같은 폴더에 붙여넣기: 복사는 `- 복사본`으로, 잘라내기는 아무 변화 없이 끝난다
- [ ] 복사한 사진이 갤러리 앱에 보인다
- [ ] 볼륨 간 이동(내부 ↔ SD) 뒤에도 수정한 날짜가 유지된다

### 뒤로 가기와 키보드

- [ ] 기록·선택·열린 메뉴가 없을 때 예측형 뒤로 가기로 홈 화면으로 나간다
- [ ] 하드웨어 키보드 단축키가 뷰어를 닫은 뒤에도 동작한다(Ctrl+C/X/V/A, Delete, F2, F5, Alt+←/→/↑)
- [ ] 검색 상자에 포커스가 있을 때 Alt+←가 동작하고, Backspace·Ctrl+A/C/V/X는 텍스트 편집에 쓰인다
- [ ] 검색 상자에서 한국어 IME로 입력하는 동안(조합 중)에는 검색이 실행되지 않고, 확정하면 실행된다

### 이미지

- [ ] 헤더만 읽어 구분하는 애니메이션 GIF/WebP 확인: 애니메이션은 재생되고, 정지 GIF/WebP는 정지 이미지로 열린다
      (애니메이션이 32 MiB를 넘으면 정지 이미지로 보인다)
- [ ] 큰 사진을 확대하면 디테일이 선명해지고(더 높은 해상도로 다시 디코딩) 메모리가 부족해지지 않는다
- [ ] 썸네일 격자를 빠르게 스크롤하거나 볼륨을 꺼내면 `ThumbnailUtils` 작업이 곧바로 멈춘다

### 동영상·오디오

- [ ] 동영상을 보다가 홈으로 나갔다 돌아오면(`ON_STOP` 이후) `VideoView`가 다시 준비되어 그 위치에서 이어진다
- [ ] 오디오·동영상을 닫았다가 다시 열어도 재생 컨트롤이 정상이다

### PDF

- [ ] 실제 `ParcelFileDescriptor`/`PdfRenderer` 실패(손상된 파일, 읽을 수 없는 파일)가 "손상된 파일" 안내로 나온다
- [ ] 암호로 보호된 PDF가 Android 15(API 35) 이상에서도 "암호로 보호된 PDF" 안내 + 다른 앱으로 열기로 나온다
- [ ] 확대한 PDF를 한 손가락으로 이동(pan)하고 핀치로 확대/축소하는 느낌이 자연스럽다

### ZIP

- [ ] Windows(한국어)에서 만든 ZIP(CP949 이름, 예: `가.txt`/`각.txt`)을 풀면 이름이 깨지지 않는다
- [ ] 실제 `zip -P`로 만든 암호 ZIP을 풀려고 하면 "손상되었거나 암호로 보호된 ZIP입니다"가 나온다
- [ ] 같은 이름의 항목이 두 개 든 ZIP을 풀면 둘 다 남고 요약에 중복이 표시된다
- [ ] Android 14(API 34) 이상에서 `..`이 든 경로의 ZIP이 "안전하지 않은 경로가 있어 압축을 풀 수 없습니다"로 거부된다
      (`ZipPathValidator`)
